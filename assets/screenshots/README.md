# Screenshots

## 目的

存放案例的运行截图，作为「能跑通」的视觉证据。每张截图应能对应到某个 Case 的某个步骤。

## 状态

**No screenshots yet — do NOT commit fake images.**

V0.1 阶段没有任何案例跑通，自然没有真实截图。**严禁**用 AI 生成图、PS 合成图、或从网络扒图冒充运行证据（这违反项目最高优先级的「诚实」原则）。

## 命名约定（未来使用）

- 格式：`<case-name>-<step>-<nn>.png`，如 `001-ai-chat-step3-01.png`
- 每张图旁边建议附一个同名 `.md` 说明：哪一步、预期、实际结果、时间。
- 截图必须来自真实运行，禁止编辑画面以伪造结果。

> ⚠️ 若某案例声称已完成但本目录无对应截图，应在案例中标注 `⚠️ Not Yet Verified`。
