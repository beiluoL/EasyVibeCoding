# 需求规格 - AI Agent

## 功能需求 (FR)
- FR1 理解任务：能解析用户自然语言任务，识别需要哪些工具
- FR2 拆解步骤：把多步任务拆成可执行的子步骤序列
- FR3 调用工具：按工具 schema 生成 JSON 调用并执行
- FR4 汇总答案：把多步结果汇总成最终答复
- FR5 承认做不了：当工具不支持或会失败时，明确说"做不了"而非编造

## 非功能需求 (NFR)
- NFR1 单任务 < 30s（不含等待用户确认）
- NFR2 有权限确认机制（confirm 类工具需人批）
- NFR3 有循环上限（默认 5 轮），防死循环
- NFR4 工具调用日志可追溯

## 验收标准
- [ ] AC1 给"查北京明天天气并算温差"类任务，能正确串起 ≥2 次工具调用
- [ ] AC2 工具不支持时，输出"做不了"而非编造
- [ ] AC3 confirm 工具触发时，先要人确认再执行
- [ ] AC4 循环超上限时，安全终止并报原因
- [ ] AC5 单任务总耗时 < 30s
