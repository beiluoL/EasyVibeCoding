# 易错点与教训 - 学习助手

## 易错点
1. 画像刻板：用一两个标签判定水平，忽略上下文
   对应：[skills/ai/memory.md](../../../skills/ai/memory.md)
2. 记忆膨胀：什么都存，prompt 越来越长
   对应：[skills/ai/memory.md](../../../skills/ai/memory.md)
3. 检索不准：query 与文档表述不一致，召回差
   对应：[skills/ai/rag.md](../../../skills/ai/rag.md)
4. 推荐同质化：不同用户拿到一样路线
   对应：[skills/ai/memory.md](../../../skills/ai/memory.md)

## 教训
- 画像要可更新，不是一次性标签
- 记忆设上限 + 摘要裁剪
- 检索 query 重写比直接用原话好
- 个性化字段必须真进 prompt
