# 需求规格 - 学习助手

## 功能需求 (FR)
- FR1 评估水平：根据用户回答判断当前水平
- FR2 给路线：基于水平 + 知识库出学习路径
- FR3 出练习：生成与当前阶段匹配的练习
- FR4 记进度：记住已学 / 已问，下次接着来
- FR5 答疑：回答用户疑问，引用知识库

## 非功能需求 (NFR)
- NFR1 个性化准确度目标 ⚠️ 未实测（期望同主题不同用户输出差异 > 阈值）
- NFR2 隐私不入库：用户原始身份信息不持久化
- NFR3 记忆有上限，定期裁剪
- NFR4 单次响应 < 10s

## 验收标准
- [ ] AC1 同用户两次同主题问答，第二次能引用第一次内容
- [ ] AC2 给初级 vs 进阶用户，输出路线明显不同
- [ ] AC3 问知识库外问题，回答"不覆盖"而非编造
- [ ] AC4 隐私字段不入库
