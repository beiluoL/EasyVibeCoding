# Advanced Cases

## 目的

本目录收录**高级案例**：多智能体、RAG 平台、MCP server 等复杂系统，面向想深入 AI 工程化的开发者。需要先掌握中级案例与 `skills/ai/` 下的技能。

## 状态

⚠️ **No cases yet — planned for V0.3+.**

高级案例依赖 Skill Registry 与更多 AI 技能就位，将在 V0.3 及以后推进。

## 计划中的案例方向

| 案例 | 练什么 | 用到的 Skill |
| --- | --- | --- |
| Multi-Agent System（多智能体系统） | Agent 编排 + 任务分发 + 上下文管理 | skills/ai/agent |
| RAG Platform（检索增强生成平台） | 向量库 + 检索 + 生成 + 评测 | skills/ai/rag |
| MCP Server（自建 MCP 服务） | 工具协议 + 权限 + 可观测 | skills/core + skills/devops |

> 高级案例的标准：系统级架构、有架构图（Mermaid）、有 benchmark 对比、有完整验证证据。
