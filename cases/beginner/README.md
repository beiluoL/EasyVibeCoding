# Beginner Cases

## 目的

本目录收录**入门级完整案例**：从零开始、可端到端跑通、面向小白。每个案例配合 `skills/core/` 的基础技能，让新手第一次就能产出真正能运行的软件。

## 状态

⚠️ **No cases yet — planned for V0.2.**

V0.1 阶段本目录仅有规划，尚未填充任何案例。所有案例落地后将在此登记到 `registry/cases.yaml`。

## 计划中的案例方向

| 案例 | 练什么 | 用到的 Skill |
| --- | --- | --- |
| Todo App（待办应用） | 增删改查 + 本地存储 | project-discovery / requirement-analysis |
| Markdown Notes（Markdown 笔记） | 文件读写 + 简单 UI | testing / systematic-debugging |
| Simple Landing Page（简单落地页） | 静态页 + 部署 | reuse-before-reinvent |

> 入门案例的标准：单文件或少文件可跑、依赖最少、步骤可复现、小白能跟着做完。
