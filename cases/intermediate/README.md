# Intermediate Cases

## 目的

本目录收录**中级案例**：在入门之上引入多模块、状态管理、外部依赖、简单后端或鉴权，适合已经跑通过入门案例、想进阶的人。

## 状态

⚠️ **No cases yet — planned for V0.2.**

中级案例将在 V0.2 与入门案例一同推进。落地后登记到 `registry/cases.yaml`。

## 计划中的案例方向

| 案例 | 练什么 | 用到的 Skill |
| --- | --- | --- |
| Blog with Auth（带登录的博客） | 前后端 + 鉴权 + 数据持久化 | requirement-analysis / testing |
| Dashboard（数据看板） | 多组件 + 数据可视化 + API | systematic-debugging |
| API Wrapper（API 封装工具） | 调用第三方 API + 错误处理 | evidence-over-claims |

> 中级案例的标准：多文件结构、含至少一个外部依赖、有测试、有验证证据。
