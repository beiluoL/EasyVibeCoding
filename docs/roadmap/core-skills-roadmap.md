# Core Skills Roadmap 核心技能路线图

> EasyVibeCoding Core Skills 的演进规划。不承诺日期，只定义阶段。

## 路线图

| 版本 | 目标 | 状态 |
| --- | --- | --- |
| v0.1 | 基础结构——10 个 Skill 骨架 + 模板 + 校验器 | ✅ 完成 |
| v0.5 | 跨项目验证——每个 Skill 在至少 1 个真实项目中执行 | ⚠️ 待执行 |
| v1.0 | 稳定标准——结构统一 + 职责清晰 + 有示例 + 有验证 | ✅ 结构完成 |
| v1.1 | 增加 AI 专用 Skills——Context Engineering / Memory / RAG | 📋 规划中 |
| v2.0 | Skills Registry / CLI——可搜索、可安装、可组合 | 💡 设想 |

## v0.1 → v1.0 做了什么

- 10 个 Core Skill 全部 v1.0.0 结构
- 统一 15 节结构（Purpose → Related Cases）
- 每个有 examples/ + Anti-Patterns + Validation
- 依赖图 + 矩阵 + 选择器 + 生命周期
- 质量检查清单模板

## v1.0 → v0.5 还差什么

- 10 个 Skill 全部在真实项目中执行
- 每个 Skill 有至少 1 个 Actual Development Record
- failures/ 和 cases/ 反哺 Skill 改进
- 部分 Skill 升级到 verified: true
