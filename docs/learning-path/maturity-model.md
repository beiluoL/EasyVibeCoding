# 成熟度模型（Maturity Model）

> 你现在处在哪一级？下一级该补什么？用这个模型自评。

> 术语小贴士：**Maturity Model（成熟度模型）**= 一套"从新手到高手"的分级标准，帮你定位自己、看到差距。

---

## 一句话定位

这个模型把"用 AI 做软件"的能力分成 6 级（0–5）。它和[学习路线](roadmap.md)的区别是：

| | 学习路线（Level 0–10） | 成熟度模型（Level 0–5） |
| --- | --- | --- |
| 视角 | 按主题学什么 | 按能力评你在哪 |
| 用途 | 规划学习 | 自我评估 |
| 粒度 | 细（11 级） | 粗（6 级） |

> ⚠️ **Not Yet Verified**：成熟度分级是**自我评估参考**，**不是认证**。本仓库**没有真实学员数据**，没有通过率，没有"学完 N 周达到 Level 3"的统计。所有分级描述均为能力预期，不代表已验证的群体表现。

---

## 成熟度总览

| Level | 名称 | 一句话画像 |
| --- | --- | --- |
| 0 | AI Chat User | 拿 AI 当聊天工具，问东问西 |
| 1 | AI Code Generator | 能让 AI 生成代码片段，但跑不通就卡住 |
| 2 | AI Pair Programmer | 能和 AI 协作完成小功能，能调试 |
| 3 | AI Project Builder | 能用 AI 端到端交付一个完整项目 |
| 4 | AI Agent Builder | 能构建自主 Agent / RAG 等高级 AI 应用 |
| 5 | AI Engineering | 能把 AI 应用做到生产级：监控、灰度、回滚 |

---

## 各级详解

| Level | 会什么 | 不会什么 | 用什么工具 | 应完成什么项目 | 如何判断升级 |
| --- | --- | --- | --- | --- | --- |
| **0 AI Chat User** | 用 AI 查资料、解释概念、写小作文 | 让 AI 生成可运行代码；拆任务；验证 | 任意对话型 AI（ChatGPT / Claude 等） | 无（能问清一个技术概念即可） | 能让 AI 产出一段能跑的代码，并知道它为什么不保证对 |
| **1 AI Code Generator** | 让 AI 生成代码片段；复制粘贴运行 | 系统化调试；拆任务；写测试 | AI 对话 + 本地编辑器 | 一个能跑的小脚本 | 能修一个 AI 生成代码里的 bug，而不是重新生成 |
| **2 AI Pair Programmer** | 和 AI 协作完成小功能；基本调试；简单测试 | 端到端交付；架构设计；复用 Skill | AI 对话 + 编辑器 + 测试框架 | 一个 CRUD 小功能（带测试） | 能独立用 AI 完成一个有前后端的小应用 |
| **3 AI Project Builder** | 端到端交付完整项目；拆任务；复用；验证 | Agent / RAG 等高级 AI 应用；生产级运维 | AI IDE（Cursor 等）+ Skill / Prompt 库 + CI | 一个端到端可运行的应用 | 能说清 RAG / Agent 是什么，并能动手做 demo |
| **4 AI Agent Builder** | 构建 Agent / RAG；上下文工程；工具调用 | 生产级稳定性；大规模并发；成本控制 | Agent 框架 + 向量库 + MCP | 一个能自主拆解任务的小 Agent | 能把 AI 应用部署上线，并处理监控 / 回滚 |
| **5 AI Engineering** | 生产级 AI 应用：监控、灰度、回滚、成本优化 | （此级为最高，持续精进） | 全套工程化工具链 + 可观测性平台 | 一个具备监控/灰度/回滚的上线服务 | 持续——没有终点 |

---

## 怎么用这个模型

1. **诚实自评**：别高估自己。能"生成代码"不等于能"交付项目"。
2. **看"不会什么"**：下一级要补的能力，就在"不会什么"那一列。
3. **做项目验证**：每级的"应完成项目"是硬指标——做不出来，就还没到那级。
4. **别跳级**：Level 2 没扎实就冲 Level 4，多半会在"看似能做、实则跑不通"里打转。

> ⚠️ 再次提醒：以上分级**无真实学员数据支撑**，是经验性的能力描述，用于自我定位，不构成任何认证或承诺。
