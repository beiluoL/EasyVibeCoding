# Level 0 — 什么是 Vibe Coding

> 小白的第一站。这一级你不写代码，只搞懂一件事：**用 AI 写代码到底是怎么回事**。

> 术语小贴士：**Vibe Coding**（凭感觉编程）= 你用大白话告诉 AI 想要什么，AI 帮你生成代码。你像"指挥"，AI 像"施工队"。但工程化要求你不只是瞎指挥，而是有章法地指挥。

---

## 目标

- 搞清楚 **Vibe Coding 是什么、不是什么**。
- 理解 **AI 写代码的基本原理**（不用深入，知道大概就行）。
- 完成**第一次和 AI 的有效对话**——问出一个技术概念，并判断 AI 回答靠不靠谱。

---

## 知识

### 1. 什么是 Vibe Coding

一句话：**你不写代码，你用自然语言描述需求，让 AI 生成可运行的代码。**

举个生活类比：

| 传统写代码 | Vibe Coding |
| --- | --- |
| 你自己炒菜（切菜、调火、下锅） | 你点菜（告诉厨师要什么），厨师（AI）炒给你 |
| 你得会语法、会调试、会部署 | 你得会描述需求、会判断结果、会拆任务 |
| 门槛在"会写代码" | 门槛在"会和 AI 沟通 + 工程化思维" |

### 2. Vibe Coding ≠ 让 AI 直接写整个项目

这是新手最大的误解。区别在于：

| | 让 AI 直接写整个项目 | Vibe Coding（工程化） |
| --- | --- | --- |
| 怎么做 | 一句话甩给 AI："帮我写个淘宝" | 拆成需求→设计→实现→测试→验证 |
| 结果 | 大概率跑不通，且改不动 | 一步步能跑、能测、能维护 |
| 原则 | 没有 | Principle 02 拆小任务、Principle 04 要证据 |

### 3. AI 写代码的基本原理（极简版）

详细版见 [02-how-ai-coding-works.md](../getting-started/02-how-ai-coding-works.md)。这里只要知道：

> AI（其实是大语言模型 LLM）根据你给的"上下文"，预测"接下来最可能出现的代码"。它**不保证正确**——所以你必须验证（Principle 04）。

> 术语小贴士：**LLM**（大语言模型）= 一个读过海量文本的 AI，能根据上文猜下文；**上下文**= 一次对话里 AI 能看到的所有信息。

## 练习

1. **问一个技术概念**：挑一个你不懂的词（比如"什么是 API"），用你自己的话问 AI，让它用大白话解释。
2. **判断回答质量**：读 AI 的回答，问自己三个问题：
   - 它有没有用我听不懂的词糊弄我？
   - 它举的例子我能不能复述给别人？
   - 如果它说错了，我有没有办法发现？（提示：换一种问法再问一次，看前后是否矛盾）
3. **对比两种问法**：
   - ❌ 错误问法："给我讲讲编程"
   - ✅ 正确问法："我是一个完全不懂编程的人，请用做菜来类比，解释什么是 API，并举一个生活中的例子"
