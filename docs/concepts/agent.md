# AI Agent 智能体

## 是什么

AI Agent（智能体）是一个能自主走完多个步骤的 AI。大白话：你给它一个目标，它自己拆任务、调用工具、读中间结果、决定下一步，直到把事办完或卡住来找你。

普通 AI 对话是"你问一句它答一句"，Agent 是"你给目标，它自己来回跑好几趟"。

## 和普通 AI 对话的区别

| 维度 | 普通 AI 对话 | AI Agent |
| --- | --- | --- |
| 交互方式 | 一问一答，每步都要你推动 | 给目标，自主多步推进 |
| 步数 | 单轮或少数几轮 | 可达数十步，自己决定下一步 |
| 是否用工具 | 通常只是生成文字 | 会调用工具（搜索、读写文件、跑命令） |
| 谁做决策 | 人决定每一步 | AI 在边界内自己做决策，人做关键审批 |
| 适用场景 | 解释概念、改一段代码、问问题 | 完成一个有明确目标的多步任务 |
| 风险 | 低，影响有限 | 高，可能改动文件、执行命令，需人审批 |

## 为什么重要

原则 07 From Prompt to Production——从一句话到能上线，中间有大量"读代码、改代码、跑测试、看报错、再改"的循环。这些循环让人手动推太累，交给 Agent 能显著降低操作成本。

但 Agent 自主权越大，风险越高，所以原则 05 Human owns decisions 要求：高风险动作（删文件、发版、改生产配置）必须人来批准。

## 什么时候用

- 目标明确、但步骤多、且每步都依赖上一步结果（如"把这个 Bug 修到测试通过"）
- 需要反复读写文件、跑命令、看输出再决策
- 你愿意在关键节点做审批，而不是全程盯着

## 怎么用

1. 给 Agent 一个清晰的目标 + 边界（哪些能做、哪些不能做）
2. 提供"工具"：能读哪些目录、能跑哪些命令、能不能改文件
3. 设定检查点：高风险动作（删除、发布、改生产）必须先问你
4. 让它把每步做了什么、结果如何记下来，便于事后核查（原则 04）
5. 卡住或遇到模糊决策时，让它主动找你而不是硬猜

相关技能见 [`skills/ai/agent`](../../skills/ai/agent)。

## 常见误用

- **给 Agent 全自动权限就放手不管**：Agent 可能"自信地"删错文件或改坏配置。高风险动作必须人审批（原则 05）。
- **目标给得太模糊**：Agent 没有客观目标就只能瞎跑。先想清楚"做到什么算完成"（见 [verification](./verification.md)）。
- **不给工具却要它干活**：Agent 不能读文件、不能跑命令，就退化成普通对话，谈不上"自主"。
- **把 Agent 当万能的**：复杂任务它也会出错、会幻觉。每步产出仍需验证，不能因为它"自己跑完了"就跳过验收。
