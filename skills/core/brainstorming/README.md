# Brainstorming（方案发散与收敛）

> 别锁死第一个想到的方案，先发散再收敛。

## What（是什么）

面对开放性技术决策，列至少 3 个候选方案，对比优缺点与风险，选一个并说明理由，记录否决方案。

## When（何时用）

- 技术选型（存哪、用什么框架）
- 多条可行路径不确定哪个
- 架构设计定技术栈之前

## How（怎么用）

1. 列 ≥3 候选
2. 每方案列优缺点 + 风险
3. 做对比表
4. 选 1 个 + 理由
5. 记录否决方案
