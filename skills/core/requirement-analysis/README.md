# Requirement Analysis（需求分析）

> 把目标拆成"做完没"能检验的需求清单。

## What（是什么）

把 Project Brief 拆成需求清单，分功能性需求（FR = 产品能做什么）和非功能性需求（NFR = 做得好不好，如速度/安全），每条配验收标准。

## When（何时用）

- Project Brief 已确认
- 要把目标变成可执行清单
- 架构设计/方案选型之前

## How（怎么用）

1. 从 Brief 提取功能点
2. 每点写成"用户能做 X"
3. 标 P0/P1/P2
4. 补 NFR
5. 每条写验收标准
