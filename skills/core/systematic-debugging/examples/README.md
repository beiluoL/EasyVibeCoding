# Systematic Debugging 示例 — 笔记保存后列表不刷新

## 输入

```
Bug 现象：新建笔记后，列表页不显示新笔记。
触发：用户反馈"保存了但看不到"
```

## 走完 6 步

### 1. 稳定复现

操作步骤：新建笔记 → 填标题和内容 → 点保存 → 返回列表。

每次都必现，Bug 可稳定复现。✅

### 2. 缩到最小用例

砍掉无关操作：不编辑其他笔记、不切换分类，只做"新建 → 看列表"。

依然必现，最小用例确定。

### 3. 二分定位

嫌疑范围有三块：保存接口、列表查询接口、前端刷新逻辑。

```
① 测保存接口 → 查数据库，新笔记确实存进去了
   → 保存没问题，排除

② 测列表查询接口 → 直接请求 GET /api/notes，返回数据里有新笔记
   → 查询没问题，排除

③ 剩下前端刷新逻辑 → 二分锁定
```

范围已经缩到前端：保存成功后，前端没重新拉取列表数据。

### 4. 找根因

- 表象：列表不显示新笔记。
- 根因：保存成功的回调里**没有调用 `fetchNotes()`**，列表数据没更新。
- 不是接口坏了，是保存后没触发刷新。

### 5. 最小修复

只改一处——在保存成功的回调里加一行：

```js
// 修复前
await createNote(data);

// 修复后
await createNote(data);
fetchNotes();  // 保存成功后重新拉列表
```

没动接口、没动查询逻辑、没动其他文件。

### 6. 回归验证

| 验证项 | 结果 |
|--------|------|
| 原用例：新建笔记 → 列表立刻显示 | ✅ |
| 编辑笔记功能正常 | ✅ |
| 删除笔记功能正常 | ✅ |
| 相关测试全过 | ✅ |
