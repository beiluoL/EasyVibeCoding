# Project Discovery（项目发现）

> 把"我想做个东西"变成"明确要做什么"。

## What（是什么）

动手写代码前，把用户模糊想法整理成一份 Project Brief（项目简报）：一句话目标 + 给谁用 + 痛点 + MVP。先聚焦"做什么"，不谈技术。

## When（何时用）

- 用户只有一句话想法
- 项目刚启动，还没有文档
- 进入需求分析前

## How（怎么用）

1. 听用户大白话讲想法
2. 复述成一句话目标
3. 问 3 个问题：给谁用 / 解决什么痛点 / MVP 是啥
4. 写出 Project Brief
5. 让用户确认
