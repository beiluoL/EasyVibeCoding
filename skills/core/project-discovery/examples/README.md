# 示例：从"做个记笔记的网站"到 Project Brief

## 输入（用户原话）

> 给我做个能记笔记的网站，就是能写、能存、下次打开还在那种，别太复杂。

## 过程

**1. 复述成一句话目标**

做一个网页笔记应用，让普通人能随时写笔记、保存、下次还能看到。

**2. 问 3 个关键问题（示例回答）**

- 给谁用？——自己用，记点灵感、待办。
- 解决什么痛点？——现在用手机备忘录太散，想有个固定地方写。
- MVP 是啥？——能新建/编辑/删除笔记，刷新还在就行。不做登录、不做分享、不做富文本。

## 输出（Project Brief）

```yaml
项目名: 极简笔记网
一句话目标: 做一个网页笔记应用，让普通人能随时写笔记、保存并持久化。
给谁用: 想要固定地方记录灵感和待办的个人用户。
痛点: 手机备忘录分散、找不到固定记事入口。
MVP:
  - 新建笔记
  - 编辑笔记
  - 删除笔记
  - 刷新页面笔记还在（持久化）
暂不做: 登录注册、分享、富文本排版、图片上传
为什么: 给自己一个极简、不被打扰的记录角落。
```

## 要点

- 目标 1 句话搞定
- MVP 砍到只剩 4 个核心动作
- 全程没提技术栈
