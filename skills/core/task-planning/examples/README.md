# 示例：笔记网站任务清单

## 输入（需求/架构摘要）

前端 Vue+Pinia，后端 Node+Express+SQLite，REST 接口。功能：新建/编辑/删除/列表/持久化。

## 输出（有序任务清单）

| 序号 | 任务 | 依赖 | 验收点 |
|------|------|------|--------|
| 1 | 建项目骨架（前后端目录、依赖初始化） | - | 前后端能分别启动 |
| 2 | 定义 Note 数据模型 + 建表迁移 | 1 | SQLite 有 notes 表 |
| 3 | 后端 CRUD 接口（GET/POST/PUT/DELETE） | 2 | curl 能完成增删改查 |
| 4 | 前端 API 封装 + Pinia store | 1,3 | 前端能调通后端接口 |
| 5 | 笔记列表页 | 4 | 进入首页看到所有笔记 |
| 6 | 新建/编辑笔记页 | 4,5 | 能新建和编辑并保存 |
| 7 | 删除笔记功能 | 5,6 | 能删除且刷新不复现 |
| 8 | 持久化验证 + 首屏性能检查 | 5,6,7 | 重启数据不丢、首页 <1s |

## 要点

- 8 个任务均 < 半天
- 每个任务都有验收点
- 依赖关系清晰（如 6 依赖 4、5）
- 按拓扑顺序排列，可逐步执行
